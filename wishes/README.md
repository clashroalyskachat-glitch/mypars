# Доска пожеланий

Страница `/mypars/wishes/` — гости пишут идеи, замечания и спасибо колледжу
без регистрации. Записи хранятся в Google Таблице (лист «Пожелания»), потому
что GitHub Pages не умеет сохранять данные.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | разметка страницы |
| `styles.css` | кожаная доска, записки на кнопках, тёмная и светлая темы |
| `app.js` | загрузка, отправка, лайки, фильтры, тема |
| `api.js` | адрес `/exec` (тот же, что у библиотеки) |
| `admin.html` + `admin.css` + `admin.js` | админка: удаление и модерация пожеланий и книг, вход по паролю |

Админка не имеет ссылок ни откуда — открывается только по прямому адресу
`/mypars/wishes/admin.html`. Как её включить, написано в
[`../library/backend/README.md`](../library/backend/README.md), раздел «Админка».

## Сервер

Доска живёт в том же скрипте Apps Script, что и библиотека:
[`../library/backend/Code.gs`](../library/backend/Code.gs).
Инструкция по включению — в
[`../library/backend/README.md`](../library/backend/README.md), раздел
«Доска пожеланий».

Отдельного проекта, отдельной таблицы и отдельного адреса не требуется.
Если когда-нибудь понадобится развести их, впиши новый `/exec` в `api.js`.

## Как это работает

- `GET /exec?action=wishes` → `{ ok, moderated, wishes: [...] }`
- `POST` с `{"board":"wishes","action":"add", text, name, kind, website}`
- `POST` с `{"board":"wishes","action":"like", id, voter}`

Запросы без `board: "wishes"` по-прежнему обслуживают библиотеку, поэтому
обновление скрипта не ломает книги.

## Ограничения

- Текст — до 600 символов, имя — до 32.
- Ссылки, почта и «заборы» из одинаковых букв сразу уходят в карантин
  (`approved = FALSE`) и на доске не появляются.
- Свыше `WISH_BURST_PER_HOUR` пожеланий в час новые тоже уходят в карантин:
  доска не встанет, но мусор не опубликуется.
