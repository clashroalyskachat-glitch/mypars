# Библиотека

Личная электронная библиотека: статический сайт без сборки и зависимостей.
Книги (PDF) лежат в Google Drive, открываются прямо на странице через встроенную
читалку Google Drive.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка: шапка, поиск, сетка книг, читалка, диалог добавления |
| `styles.css` | вся визуальная система, тёмная тема, адаптив, анимации |
| `books.js` | **список книг** — единственный файл, который нужно править для новых книг |
| `app.js` | поиск, фильтры, избранное, читалка, тема, добавление книг |
| `sw.js` | service worker: офлайн-оболочка сайта |
| `manifest.webmanifest` | установка сайта как приложения |
| `icon.svg` | иконка |

## Как добавить книгу навсегда

1. Загрузи PDF в Google Drive.
2. Правый клик по файлу → **Поделиться** → **Все, у кого есть ссылка** → роль
   «Читатель». Без этого iframe покажет «нет доступа».
3. Скопируй ссылку вида
   `https://drive.google.com/file/d/XXXXXXXXXXXX/view?usp=sharing`.
4. Открой `books.js` и добавь объект в массив `window.BOOKS`:

```js
{
    id: 'social-studies-spo-1',   // уникальный, латиницей
    title: 'Обществознание',
    subtitle: 'СПО',              // необязательно
    author: 'Котова О. А., Лискова Т. Е.',
    subject: 'Обществознание',    // по этому полю строятся фильтры
    course: '1 курс',
    driveId: '11q7K4LaaoQYJaXY_RpibVSQxkOPVpGC2', // часть между /d/ и /view
    added: '2026-10-25'           // для сортировки «сначала новые»
}
```

5. Закоммить и запушь — на сайте книга появится после обновления страницы.

## Добавление через сайт

Кнопка **Добавить** сохраняет книгу в `localStorage` этого браузера — удобно
для быстрой проверки ссылки. Чтобы книга была на всех устройствах, нажми
**Скопировать код** в том же окне и вставь результат в `books.js`.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Библиотека"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch →
Branch: main / (root)**.

Файл `.nojekyll` уже лежит в папке — он отключает обработку Jekyll и не даёт
ей ломать файлы, начинающиеся с подчёркивания.

## Локальный просмотр

Из папки проекта:

```bash
python -m http.server 8093
```

и открыть `http://localhost:8093`.

## Особенности

- Тема запоминается в `localStorage`, применяется до первой отрисовки.
- Анимации только на `transform`/`opacity`, уважается `prefers-reduced-motion`.
- Если книга не открылась в читалке — кнопка **В Drive** открывает её напрямую.
- Service worker кэширует только сайт, книги всегда грузятся с Google Drive.
